# 🚀 Firebase Deployment

## Step 1 — Install Firebase CLI

```bash
npm install -g firebase-tools
```

## Step 2 — Login Firebase

```bash
firebase login
```

## Step 3 — Initialize Firebase

```bash
firebase init
```

## Step 4 — Deploy Project

```bash
firebase deploy
```
